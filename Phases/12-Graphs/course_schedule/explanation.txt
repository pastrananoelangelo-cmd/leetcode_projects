Pattern:
Graph + DFS + Backtracking

For every numCourses, perform backtracking and DFS.
While in DFS:
    For every current node, store them in set.
    If it reaches the end, store them in visited, to avoid
    visiting them again.
If the current node is in set, return false as there is a cycle.
Otherwise, continue looping, and if no cycle is detected, return true.

Recursive State:
    Map<Integer, List<Integer>>, graph
    Set<Integer> set, (Nodes currently in the recursion path)
    Set<Integer> visited, (Nodes already completely processed)
    curr, Current course

Invariant: 
1. Every node in path belongs to the current DFS recursion path.
2. Every node in visited has already been completely processed
   and cannot be part of a cycle.
3. If DFS reaches a node already in path, a cycle exists.

Time Complexity: O(V + E)

Idea:
Graph: Backtracking + DFS (Boolean Search)

Base Case: If Current Node is already in set (there's a cycle):
    return false

For each neighbor:
    If DFS(neighbor) returns false:
        return false

Current Node reaches the end:
    remove current from path
    add current to visited
    return true


Example:
    0
   / \
  1   2
   \ /
    3

Input: [[1,0],[2,0],[3,1],[3,2]]

Transform to HashMap (Adjacency List):
0 - 1, 2
1 - 3
2 - 3
3

dfs(0):
    set = [0]
    dfs(1):
        set = [0, 1]
        dfs(3):
            set = [0, 1, 3]
            visited = [3]
            set = [0, 1]
            return true
        visited = [3, 1]
        set = [0]
        return true
    dfs(2):
        set = [0, 2]
        dfs(3):
            3 is already visited
            return true
        visited = [3, 1, 2]
        set = [0]
        return true
    visited = [3, 1, 2, 0]
    set = []
    return true
return true
