Pattern:
Graph DFS + Deep Copy

Traverse the graph using DFS while creating a cloned node 
for each original node. Use a HashMap<OriginalNode, ClonedNode> 
to ensure each node is cloned only once and to reconnect 
cloned neighbors correctly.

Recursive State:
Current Position:
    node — the current original node being cloned.
Shared Data:
    HashMap<Node, Node> map
    Key: Original node.
    Value: Cloned node.

Invariant: 
For every original node that has been visited:
    1. Exactly one cloned node exists.
    2. The original node and its clone are stored in map.
    3. If a node is encountered again, reuse the existing clone 
    instead of creating a new one.
    4. Every recursive call returns the clone of the current node 
    after all of its cloned neighbors have been connected.

Time Complexity: O(V + E)
Where:
    V = number of vertices (nodes)
    E = number of edges

Each node is cloned exactly once, and each edge is traversed 
once (twice in an undirected graph, but that's still linear).
