State:
dp(x) returns the minimum number of coins needed to make the remaining amount (x).

Decision for each state:
What is the minimum number of coins given the current amount?

How do I transition to smaller states?
Subtract the current amount to the current coin.

Base Case:
If amount = 0, return 0.
If amount < -1, it is impossible, return the highest amount (Integer.MAX_VALUE);

Idea:
coins = [1, 2, 5]
target = 6

dp(6) = 2 [5 + 1]
dp(5) = 1 [5]
dp(4) = 2 [2 + 2]
dp(3) = 2 [2 + 1]
dp(2) = 1 [2]
dp(1) = 1 [1]
dp(0) = 0

dp(6) = 1 + min(
    dp(5),
    dp(4),
    dp(1)
)

dp(5) = 1 + min(
    dp(4),
    dp(3),
    dp(0)
)

dp(4) = 1 + min(
    dp(3),
    dp(2),
    dp(-1) // Impossible
)

dp(3) = 1 + min(
    dp(2),
    dp(1),
    dp(-2) // Impossible
)

dp(2) = 1 + min(
    dp(1),
    dp(0),
    dp(-3) // Impossible
)

dp(1) = 1 + min(
    dp(0),
    dp(-1), // Impossible
    dp(-4) // Impossible
)

dp(0) = 0
